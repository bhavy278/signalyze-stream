# Contributing

## Branching
Work on short-lived branches off main: feat/..., fix/..., docs/...
Open a Pull Request (even solo), let checks run, then merge.

## Commit messages (Conventional Commits)
Format: type(scope): summary
Example: feat(ingest): publish DocumentUploaded event
Types: feat, fix, docs, refactor, test, chore.

## Before you push
- Code builds and tests pass
- Docs updated (README, service README, or an ADR)
- No secrets committed
