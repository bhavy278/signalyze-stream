# Screenshots

Drop these into `docs/images/` and the main README renders them:

- `viewer.png`   — the Document tab: the contract open in the in-app viewer (toolbar + a search highlight is a nice touch)
- `analysis.png` — the Analysis tab: document type, parties, key terms, and risk flags (the money shot)
- `chat.png`     — the Chat tab: a streamed answer with an expanded "Sources" citation

Optional but high-impact:

- `demo.gif` — a 5–8s screen capture of clicking **Try a sample contract** and the analysis overview typing out live. On macOS, Cmd+Shift+5 records; convert the `.mov` to GIF (e.g. `ffmpeg -i demo.mov -vf "fps=12,scale=900:-1" demo.gif`).

Tip: capture just the app (crop out the browser tabs / URL bar) for a clean look. Use the sample contract for repeatable, professional-looking shots.
